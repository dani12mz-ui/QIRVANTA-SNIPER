# Phase 11 champion and challengers

The roster registers four independent wallets for each instrument. XAUUSD and BTCUSD have separate journals, budget parameters, timeframes and summaries.

| Strategy | Input and lifecycle |
| --- | --- |
| CHAMPION | Authenticated production TradingView native submission with the frozen core hash, exact chart-to-broker symbol and timeframe mapping, confirmed bar, timely receipt and matching broker closed bar. Original reference, stop and targets enter local paper controls. |
| S3 | Existing causal acceptance-retest model. |
| S5 | Existing causal failed-breakout reversal model. |
| S8 | Existing causal momentum-continuation model. |

F1 remains rejected. S3, S5 and S8 use fixed experimental rules from the research library. The CHAMPION status is BLOCKED_EXTERNAL without a pinned external core. A configured wallet requires one eligible reconciled alert and matching broker evidence. Conflicting, expired or unavailable alerts cannot trigger a paper entry. The paper fill rule, cost model, partial quantities and management are local and common to the registered wallets. They can yield different outcomes from the Pine strategy tester.

Each wallet has its source and parameters pinned in the registration and in a hash-verified journal. An eligible observation uses the same broker quote and closed-bar cutoff for each wallet of the instrument. A strategy's veto, cash losses and exposure affect only that wallet. Compare results within one symbol and timeframe. Without eligible alerts the report identifies missing champion evidence and reports challenger results independently.
