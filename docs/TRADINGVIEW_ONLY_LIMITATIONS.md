# TradingView Only · Ограничения на доказателствата

| Проверка | Граница |
| --- | --- |
| Продукт | Една Pine v6 стратегия и едно нативно симулирано портфолио на run. Предходната история в Git е запазена. |
| История | Трите рамки имат различни налични пълни периоди и различен часов еквивалент на баровите хоризонти. Съпоставимостта е фиксирана вътре във всяка рамка. Общият прозорец между рамките е cohort от наблюдавани кампании. |
| Емулатор | OHLC последователност по платформения модел, без включен Bar Magnifier. Порядъкът в една свещ и fill при gap могат да се различават от пазара. |
| Управление | Опционалните структурни, trailing и BE настройки имат статични и синтетични проверки. Нативната основна матрица държи управлението по подразбиране. |
| Доказателство | Пълната стратегия компилира. Отделен наблюдател без модул за рисуване и `alert()` dispatch събира нативните журнални редове в лимита на компилатора. |
| Доставчик | Потвърдените данни са OANDA в TradingView. Липсващ volume тип, дупка или незавършен ден блокира S6. Няма видимост към реални стоп поръчки. |
| Модели | S10 и неподкрепените варианти A–L нямат самостоятелна нативна селекция. Повтарящите се идеи са сведени до общи правила. |
| KN | Оригиналният източник е прочетен в TradingView. Общият benchmark използва потвърдени сигнали и отделен offline execution wrapper. Точно native сравнение на двата продукта е непотвърдено. |
| Мобилност | Тесният браузърен viewport показва числата на активен исторически план. Горният ред може да пресече легендата или свещите. Действително физическо устройство и стратегия push остават непроверени. |
| Статистика | 62 runs включват два блокирани режима. Наблюденията са исторически и зависими. Описателните bootstrap интервали и Holm корекцията не заместват независим бъдещ тест. |

Мисията оставя фиксиран проспективен протокол за бъдещо изпълнение. Няма приключени проспективни кампании или установена подобрена доходност. [Протокол и резултати](TRADINGVIEW_ONLY_NATIVE_COMPARISON.md)
