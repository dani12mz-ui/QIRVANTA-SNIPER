# Фаза 10 · Локален операторски процес

**IMPLEMENTED / LOCALLY_TESTED.** Прегледът на текущото дърво откри Python CLI, Pine, HTML mockups и отчетни инструменти. Липсва съвместимо native Windows приложение за разширяване. Добавеният `python -m qirvanta_ultimate` управлява архивен анализ, календарна проверка, локален paper spool, SQLite journal, пауза, health, отчет и известия.

`serve` чете локални JSON пакети от операторски spool. Обработва стабилния прочетен пакет и подрежда котировките в текущата партида по UTC време. Записва закъснелите или повредени входове като отхвърлени fingerprints, без да разкрива суровия payload. Идентичният пакет след рестарт не повтаря ефектите. Startup сверява замразената конфигурация и версия. Health показва integrity head, брой събития, актуалност на котировката и отделен статус на broker/model връзките.

Локалните уведомления са на български. Известията за предложение отделят нива от симулиран вход, TP или стоп. Записват се със статус `PERSISTED_LOCAL` и trace ID. CLI показва журнала. Транспортът не изпраща към външни получатели. Telegram и push доставка изискват отделен разрешен канал, удостоверяване и реална проверка на получаването.

Изпълнени са CLI startup с празен spool, регистрация преди тестовия прозорец, health след рестарт, отчет и отказ на drift преди startup статус. 22-те локални теста включват и синтетичен пълен lifecycle. Локалното `pip check` не намери несъвместими зависимости. Подписан Windows EXE, външен installer, latency stress на борсов поток, дългосрочен uptime, автоматично стартиране и production observability са извън изпълнената проверка.
