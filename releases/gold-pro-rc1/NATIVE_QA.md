Таблото маркира историческия преглед и показва референтен вход, начален SL и TP1–TP3 от съответния `READY` запис. Реалният опит за създаване на известие в тестовия Basic акаунт показа лимит **0 технически известия**. Push доставка и iPhone получаване остават непроверени. ## Оставащи проверки

- При опит за **Save** TradingView показа, че тестовият Basic акаунт има лимит **1 запазен скрипт** и мястото е заето. RC1 беше зареден временно в Pine Editor. Постоянно запазване като нов частен скрипт и възстановяване след презареждане остават непотвърдени. [Екран на ограничението](screenshots/10-save-platform.jpg)
- Изтичането на Wick формация е проследено по условията в кода. Липсва нативен визуален пример за този преход.
- RC1 е проверен в рамките на лимита от 1200 изчислявани свещи. Наличната история определя кои случаи могат да се повторят в `FULL AUDIT`.

## Възпроизвеждане

От корена на хранилището изпълни следните команди в PowerShell. Генераторът извежда и контролния S5 Pine файл с диагностичния журнал. При `PARTIALLY_COMPLETE` валидаторът записва JSON и връща код 1, за да останат видими непокритите случаи.

```powershell
Expand-Archive -LiteralPath releases/gold-pro-rc1/evidence/native-logs.zip -DestinationPath extracted
python -B unified/tools/build_gold_pro_rc1.py --check
python -B unified/tools/build_gold_pro_rc1.py --reference-out extracted/pinned_s5_reference.pine
python -B -m gold_pro.rc1_qa --native-dir extracted/strict --visual-recheck-dir extracted/final --output extracted/parity.json
```
